# 通用数据采集平台 · 业务逻辑与参数化维度(v1.0)

> 本文是**代码契约**:每个参数维度给出 键路径 / 类型 / 缺省值 / 消费方。
> 缺省值 = 今天 sec_events 的行为;老画像不填新键也能跑。引擎只从 `NeedContext` 取参。

---

## 1. 通用业务逻辑(与需求无关的骨架)

下面按流水线阶段列出:**引擎做什么(固定)** 与 **画像决定什么(参数)**。

| 阶段 | 引擎固定逻辑 | 画像参数(见 §2 编号) |
|---|---|---|
| ① 源层:种子/发现/找源/定位栏目/体检/定级/自动运维 | 一源多需求;候选池评分与多通道闸门;栏目结构一致性;时间预算护栏;引擎自检与切题率 | 种子清单 C1、信誉名录 C2、找源配方与自检词 B3/B8、栏目提示词 B5、地域策略 C6、定级规则 C3、评分权重 C4 |
| ② 采集层:适配器/渲染/反爬/翻页早停/时效/存档 | 全部平台级;`render=auto`、早停、时效窗口、广采薄存 | 无(运行时设置) |
| ③ 去重:URL / 文档 SimHash / 记录指纹+语义 | 前两层完全通用;第三层按**去重键**比对 | 记录去重键 A7 |
| ④ 粗筛 | 平台固定输出格式 `{is_candidate, relevance, confidence, reason}`,相关度阈值双重把关 | 判定目标、算相关清单、必须判否清单 D1 |
| ⑤ 抽取 + 断言守卫 | 平台通用硬规则(不臆造/未披露用 status/附原文片段/日期精度)+ Schema 校验;**断言三态守卫**按语境词降级、隔离规则、待人工标记 | 领域抽取规则 D2、三态字段与语境词 D4、范畴闸门 D3 |
| ⑥ 建草稿 | 事件号、反规范化查询列、record_type 推断、来源兜底、可信度按主体重定级、embedding | 前缀 A2、字段角色 A3、记录类型 A6、置信度映射 A9 |
| ⑦ 复核发布 | 状态机 extracted→first→[second]→published;含"确认"断言即双签;发布红线校验 | 允许确认的等级 C2、双签字段 D5 |
| ⑧ 生命周期 | 发布后按节奏生成 T+N 回访任务与检索包;到期派发 | 回访节奏 E1、触发条件 E2、检索包 E3 |
| ⑨ 输出 | 线索引擎、四类报表引擎、日报、KPI 看板、动作台账 | 线索 F1、报表 F2、日报 F3、界面 G* |
| ⑩ 进化回路 | 覆盖空白→找源词;找源词按产出进化;语料挖新词;引擎自检 | 覆盖维度 B4、挖词提示 B7 |

**记录四型的引擎差异**(9A)只体现在两处:③ 第三层去重键、⑧ 生命周期语义。其余阶段四型共用。
