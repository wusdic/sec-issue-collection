# 平台设计文档 · 索引(v2.0)

> 平台以**任务**为运行单位:每新建一个任务,就规定这个任务要干的事(采集什么信息、多久一次、用什么参数);参数为任务服务;

## 文档的统一结构

每份文档:标题下一句话说"本文回答什么" → **导读**(目的 / 读者 / 前置阅读 / 相关文档 / 章节一览表:章 → 说什么 → 包括哪些内容)→ 各章。
每一章开头先用一段话说这章讲什么、包括哪些方面,然后才是细节(表格、规则、样例)。
